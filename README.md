#  PHP GitHub Profile Card Generator

This is a dynamic and lightweight PHP-based tool created by **Ashikur Rahman Provat**. It fetches real-time data from the GitHub API and generates a sleek, professional profile card showcasing your coding stats.

### Showcase your GitHub stats with a clean UI.
The PHP GitHub Profile Card Generator not only fetches basic profile info but also calculates total stars and contributions to give a complete overview of a developer's impact.

## Features

- **Real-time Data:** Fetches live data directly from GitHub REST API.
- **Advanced Stats:** Calculates Total Stars and Total Contributions across all repositories.
- **Modern UI:** Dark-themed, minimal, and responsive design inspired by GitHub's aesthetic.
- **Lightweight:** Pure PHP and CSS logic without heavy frameworks.
- **API Handling:** Securely manages User-Agent headers and JSON parsing.

## Tech Stack

**Server:** PHP (file_get_contents, stream_context, json_decode)  
**Frontend:** HTML5, CSS3 (Modern Flexbox Design)

## How to Run

1.  Clone or download the repository to your local server (XAMPP, Laragon, or Linux Server).
2.  Ensure you have PHP installed (7.4 or higher recommended).
3.  Place the files in your web directory.
4.  Open your browser and navigate to:
`http://localhost/GitHubProfileCardGenerator/index.php`
5.  Enter any GitHub username to generate the card!

## ⚠️ Note

GitHub API has a rate limit for unauthenticated requests. If you face any "User not found" errors repeatedly, it might be due to the API limit. Using a Personal Access Token (PAT) can increase this limit if needed.
